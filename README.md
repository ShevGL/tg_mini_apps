# tg_mini_apps

Мини-приложения для Telegram. Каждое в своей папке.

Сейчас в корне — «Погода в Алматы»: `index.html` (погода, качество воздуха, совет по одежде,
пиксельный фон) и `shake.html` (шар предсказаний). Статический сайт без сборки,
единственные внешние зависимости — telegram.org (SDK) и открытые API Open-Meteo.

Адрес: https://shevgl.github.io/tg_mini_apps/
